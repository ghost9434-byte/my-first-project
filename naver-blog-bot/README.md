# 네이버 블로그 임시저장 도우미

클로드가 쓴 글(제목·본문·사진)을 맥에서 네이버 블로그 글쓰기 창에 넣고 **임시저장**까지 해 줍니다.
**발행은 회장님이 직접** 누르십니다. 네이버가 자동 발행 글을 저품질로 판단할 수 있어서입니다.

## 매일 쓰는 법

1. 클로드에게 사진과 한두 줄 설명을 보냅니다. ("오늘 점심 ○○식당, 이 사진들로 글 써 줘")
2. 클로드가 글을 써서 올려 두면, 맥 터미널에서 아래 한 줄을 실행합니다.

   ```
   bash ~/blog-bot/naver-blog-bot/post.sh
   ```

3. 크롬 창이 열려 글이 채워지고 임시저장까지 됩니다.
4. 휴대폰이나 맥에서 내용을 확인하고 **카테고리를 고른 뒤 발행**합니다.

## 처음 한 번만 하는 준비 (10분)

터미널(⌘+스페이스 → "터미널")을 열고 한 줄씩 붙여 넣으세요.

1. 프로그램 받기

   ```
   git clone -b claude/introduction-o55ejx https://github.com/ghost9434-byte/my-first-project.git ~/blog-bot
   ```

   - "명령어 도구 설치" 창이 뜨면 **설치**를 누르고, 끝나면 이 줄을 다시 실행합니다.

2. 설치

   ```
   bash ~/blog-bot/naver-blog-bot/setup.sh
   ```

3. 네이버 로그인 (자동화용 크롬 창이 따로 열립니다)

   ```
   bash ~/blog-bot/naver-blog-bot/login.sh
   ```

   - 열린 창에서 네이버에 로그인하고 **로그인 상태 유지**에 체크한 뒤, 터미널에서 엔터를 누릅니다.
   - 비밀번호는 프로그램에 저장되지 않습니다. 자동화용 크롬 창에만 로그인이 남습니다.

4. 첫 시험 (단계마다 멈추며 확인)

   ```
   bash ~/blog-bot/naver-blog-bot/post.sh 2026-10-10-hongildong --step
   ```

   - 단계마다 터미널에서 엔터를 눌러 넘어갑니다.
   - 어디서든 멈추거나 이상하면 `~/blog-bot/naver-blog-bot/logs/` 폴더의 **가장 최근 사진**을 클로드에게 보내 주세요. 보고 고쳐 드립니다.

## 알아 두실 점

- 실행 중에는 자동화용 크롬 창을 건드리지 마세요. 끝나면 터미널에 결과가 나옵니다.
- "이전에 열린 자동화용 크롬 창이 아직 켜져 있습니다"가 나오면 그 창을 닫고 다시 실행하세요.
- 로그인이 풀리면 `login.sh`를 다시 실행하면 됩니다.
- 하루 한두 편 정도, 사람이 쓰는 속도로 올리시는 것이 안전합니다.
- 네이버가 글쓰기 화면을 바꾸면 프로그램도 고쳐야 할 수 있습니다. 그때도 logs 사진을 보내 주세요.

## 폴더 구조 (클로드용)

- `posts/<날짜-이름>/post.json` : 제목과 본문. 본문은 `html`(글) 블록과 `image`(사진) 블록을 순서대로 적습니다.
- `posts/<날짜-이름>/images/` : 사진
- `make_post.py` : 사진(HEIC 포함)을 JPG로 바꿔 새 글 폴더를 만드는 도구
- `tests/run_tests.py` : 가짜 네이버 글쓰기 화면으로 13가지 경우를 시험
- `.posted` : 이 맥에서 이미 임시저장한 글 목록 (`post.sh`는 아직 안 올린 글 중 가장 오래된 것을 고릅니다)
