자동 다음 버튼

강의를 보시는 동안 "다음" 버튼만 대신 눌러 드립니다.

1. 설치 (한 번만)

아래 파란 단추를 마우스로 끌어 크롬 위쪽 북마크바에 놓으세요.
(북마크바가 안 보이면 ⌘ + Shift + B)

▶ 자동 다음

북마크바가 없는 학습창(팝업 창)일 때

  1. 아래 코드 복사를 누릅니다.
  2. 학습창을 한 번 클릭한 뒤 ⌥ Option + ⌘ Command + J 를 누르면 오른쪽(또는 아래)에 개발자 창이 열립니다.
  3. 맨 아래 > 표시 옆을 클릭하고 ⌘ + V 로 붙여 넣은 뒤 엔터.
    처음 한 번은 "allow pasting" 을 직접 쳐 넣고 엔터를 누르라는 영어 경고가 나옵니다. 그대로 allow pasting 입력 → 엔터 → 다시 ⌘ + V, 엔터.
  4. 학습창 오른쪽 아래에 파란 표시가 뜨면 성공입니다. 개발자 창은 닫아도 계속 동작합니다.

코드 복사

2. 쓰는 법

  1. 회사 교육 사이트에서 강의 창을 엽니다.
  2. 북마크바의 ▶ 자동 다음을 누르면 화면 오른쪽 아래에 파란 표시가 뜹니다.
  3. 끌 때는 그 파란 표시를 누르거나, 북마크를 한 번 더 누릅니다.

3. 이렇게 동작합니다

  1. 동영상이 있으면 끝까지 재생된 뒤에만 누릅니다. 배속·건너뛰기는 하지 않습니다.
  2. "다음" 버튼이 흐리게(눌리지 않게) 되어 있으면 켜질 때까지 기다립니다.
  3. 한 화면에 최소 10초는 머문 뒤 누릅니다.
  4. 시험·퀴즈·설문(고르는 칸이나 쓰는 칸이 있는 화면)에서는 멈추고 알려 드립니다. 직접 푸시고 넘어가시면 다시 이어서 합니다.
  5. "다음" 버튼을 못 찾으면 아무것도 하지 않습니다.
